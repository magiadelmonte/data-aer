# Telemetry — Observatorio Uritorco

Snapshot público de los **últimos 20 vuelos** detectados por el módulo **AER** del
Observatorio Uritorco sobre Capilla del Monte (Argentina).

- **Capilla del Monte**: si el recorrido del vuelo entró al radio R1 (≤ 25 km del centro) se muestra `Sí`; si no, `No` con la distancia al centro.
- **AHORA** (verde): el vuelo sigue en curso (aún sobrevolando R1/R2).
- **HOY hh:mm**: detectado hoy. Si no, `dd/mm/aaaa hh:mm`.

Página servida por **GitHub Pages**. Se regenera automáticamente cada ~60 s desde el
servidor del observatorio (snapshot; no es en vivo).

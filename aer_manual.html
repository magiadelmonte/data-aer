Identificación y foto de una aeronave (hex / matrícula / url de foto)
Aeronave
Sin correr todavía.
El backend identifica los vuelos que matcheen por hex y/o matrícula y los actualiza con la ficha local (cache). La foto se guarda con source=manual y no se re-consultan los barridos. El JSON publicado en data-aer se regenera con publish_aer.py y se publica en GitHub Pages. Con el check marcado la foto se descarga a aer/web/img/photos/ y queda commiteada; con el check desmarcado se usa solo la URL pública del sitio.
